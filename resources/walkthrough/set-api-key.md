AMD TokenFactory Provider 使用你自己的 API 密钥，让 AMD TokenFactory 的 AI 模型出现在 Copilot 模型选择器中。

只需粘贴一次，之后可通过命令面板更新或移除。

- `Cmd/Ctrl + Shift + P`：打开命令面板
- `管理 API Keys`：设置或更新 API 密钥
- `生成提交消息`：生成 Git 提交消息

[获取 API 密钥](https://developer.amd.com.cn/radeon/tokenfactory)
[管理 API Keys](command:amdtokenfactory.manageApiKeys)
