## 高级设置

通过扩展设置自定义你的体验：

- **模型预设**：通过 `amdTokenFactory.modelPreset` 设置在精确、均衡、创意或自定义温度/top_p 之间切换。
- **自动模型发现**：模型选择器会自动过滤为你账号下可用的模型。
- **多 API Key**：通过命令面板管理多个 Key（添加/批量导入/删除/设为当前/检测可用性）。某个 Key 失效时可自动轮换到其他 Key。
- **API 协议**：通过 `amdTokenFactory.apiMode` 在 OpenAI 兼容 / Anthropic 协议之间切换（或设为 `auto` 自动选择）。
- **视觉代理**：配置用于为非视觉模型描述图片的视觉模型。
- **Git 提交**：自定义提交消息语言、提示词和风格参考设置。

[管理 API Keys](command:amdtokenfactory.manageApiKeys) · [打开设置](command:amdtokenfactory.openSettings)
